## PROJECT HTML -- CSS

- Website chia sẽ mẫu giao diện: https://html.lionode.com/nature/n-speed/#

- Cấu trúc files, thư mục:

* css: Thư mục chứa các file css
*   - style.css: File css chính của dự án
*   - grid.css: File chứa code grid system
*   - reset.css: File chứa code reset css
*   - base.css: File chứa các style mặc định ban đầu
*   - responsive.css: File chứa style response
*   - animate.min.css: File thư viện animate css
*   - all.min.css: File thư viện font-awesome 5
* fonts: Thư mục chứa fonts của dự án
* webfonts: Thư mục chứa các file fonts của thư viện font-awesome
* images: Thư mục chứa các file ảnh
* js: Thư mục chứa các file javascript
* index.html: File chạy chính của dự án
* category.html: File trang danh mục
* blog.html: File trang blog
